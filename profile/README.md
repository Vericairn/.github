# Vericairn

Vericairn is a local-first creation and operations platform. It helps a person or an organization turn an
intention into an understood, authorized, produced, reviewed, delivered and maintained result, with its
decisions, sources, relationships and history intact.

- **Community** is the free foundation, Apache-2.0, commercial use included.
- **Standard** is an optional paid offering on the same core.
- **Pro** adds separately licensed coordinated production and administration.

Workbench (desktop), Remote (mobile companion), the `vericairn` command-line interface and the SDK are
surfaces of one product. Vericairn is built and maintained inside its own estate, by Vericairn.

Nothing here is a release until a release says so; see each repository for its current status.
