# Security

## Reporting a vulnerability

Report a security problem privately, never in a public issue or pull request. Use GitHub's private vulnerability
reporting: on the affected repository's **Security** tab, choose **Report a vulnerability**. If you cannot use it,
email vericairn@jasonfurr.com.

Say what you found, the repository and the release or commit it affects, and how to reproduce it. The maintainer
reads every report. Vericairn has no support commitment yet, so no response time is promised.

## What this covers

This is the default security policy for every Vericairn repository that has none of its own: the code in such a
repository and the releases published from it. A repository's own `SECURITY.md` takes precedence. Releases are
published on GitHub Releases as unsigned developer builds, and a release's documentation set lists its known
limitations.
