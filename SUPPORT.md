# Getting help

Help with Vericairn is self-service.

- **The documentation.** From 0.2.0 on, each release has its own documentation set: an overview, installation and
  cold start, the operator's guide, the command-line, API and record references, the release notes, and the known
  limitations and platforms. The sets are kept in the repository under
  [docs/releases](https://github.com/Vericairn/vericairn/blob/main/docs/releases/README.md), and from 0.3.1 on each
  release also carries its set as `vericairn-<version>-docs.zip`. Read the set of the release you run;
  `vericairn version` tells you which one that is.
- **Bugs and feature requests.** Open an issue in the repository concerned, such as
  [vericairn](https://github.com/Vericairn/vericairn/issues). Search first, and check the release's known
  limitations: what you see may already be described there.
- **Security problems.** Report them privately, never in an issue; see the [security policy](SECURITY.md).

Vericairn has no support commitment yet: there is no support offer, no staffed help and no promised response time.
