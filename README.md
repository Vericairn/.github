# .github

The Vericairn organization's profile and its default community files.

| Path | What it holds |
|---|---|
| `profile/README.md` | The organization profile shown at [github.com/Vericairn](https://github.com/Vericairn) |
| `CODE_OF_CONDUCT.md` | The code of conduct, the Contributor Covenant 2.1 |
| `CONTRIBUTING.md` | How to take part: issues are welcome, outside pull requests are not accepted yet |
| `SECURITY.md` | How to report a vulnerability privately |
| `SUPPORT.md` | Where to find help, which is self-service |
| `.github/ISSUE_TEMPLATE/` | The issue forms for bug reports and feature requests, and links to the security policy and the release documentation |
| `.github/PULL_REQUEST_TEMPLATE.md` | The pull request template |

GitHub applies these community files to every repository in the Vericairn organization that has no file of the
same kind of its own, whatever the repository's visibility. A repository's own file takes precedence, and a
repository with issue templates or a `config.yml` of its own in `.github/ISSUE_TEMPLATE` uses none of the issue
forms here.
